# Yang baru

Pembaruan dokumentasi ini, dari yang terbaru. Nomor versi tampil di header. Dokumentasi sebelumnya tetap bisa dibuka di `/docs/v1`.

## 2.0.0

- Tampilan baru: sidebar berkelompok, pencarian, tampilan Docs dan Agent, tema terang dan gelap, serta sidebar yang bisa digeser lebarnya.
- Bahasa Indonesia dan English untuk setiap halaman, dengan pengganti bahasa.
- Setiap halaman endpoint punya versi Markdown untuk AI agent, terdaftar di `llms.txt`.
- Halaman Mulai baru: API key, base URL, tabel hak akses, dan penjelasan 403 Not allowed.
- Isi dicek terhadap API yang berjalan, termasuk hak akses, respons error, dan contoh.
- Versioning docs: `/docs` dan `/docs/v2` menampilkan versi ini, `/docs/v1` menampilkan versi sebelumnya.

## 1.0.0

- Dokumentasi satu halaman berbahasa Inggris yang asli, sekarang ada di `/docs/v1`.
